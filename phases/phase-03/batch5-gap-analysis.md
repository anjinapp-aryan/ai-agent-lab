## Methodological correction (reasoning echo), applied to the plan
Batch 4 showed that Pydantic AI sends the model's earlier `reasoning` back and LangGraph drops it, which flipped decisions on `gpt-oss-120b`. For live runs the design therefore has:
- **Mode A, native:** each framework as it ships.
- **Mode B, controlled parity:** no earlier reasoning in either request.

LangGraph never sends reasoning back, so its native run **is** the controlled condition; only Pydantic AI needs a second cell. Pydantic AI Mode B uses its documented model profile option `openai_chat_send_back_thinking_parts=False`; no framework internals are changed. A condition with reasoning echoed in both frameworks is not built: it would need rewriting requests below the framework. Residual differences stay (Pydantic AI's `strict`/`additionalProperties`/`tool_choice` envelope, from Phase 2 Batch 5) and are recorded, not removed.

## Scope decisions
- Scripted offline runs are the primary evidence for 39–41, 44–47 and the mechanical parts of 40, 42 and 43.
- Live is limited to model behavior: 43 (wording), 40 (persistence and honesty), 42 (final-answer honesty), 41 (does the model repeat A).
- Nothing in Batch 3's counter arithmetic or Phase 2's ledger table is rerun to add test count.
- No new dependency and no recovery or retry helper is built. New code is an experiment runner, scripted tool fixtures, and a few measurement helpers.

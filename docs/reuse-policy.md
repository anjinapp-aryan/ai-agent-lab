# Reuse Policy

1. Hierarchy: REUSE → ADAPT → COMPOSE → BUILD.
2. Public repo ≠ open source ≠ free to reuse. Read the actual LICENSE file (`gh api repos/<r>/license`). Check `NOASSERTION` results by hand.
3. Preferred: MIT / Apache-2.0 / BSD. Others (BSL, ELv2, open-core splits, custom) are flagged; unclear cases are marked `LEGAL REVIEW REQUIRED`. This repo gives no legal advice.
4. Health = recent commits + releases + issue handling, never stars alone.
5. BUILD only if: no suitable OSS, or existing fails the learning goal, or a tiny build is needed to grasp a concept. Document why, alternatives, scope, exclusions.
6. Re-audit before each phase; evidence dated.

Evidence method used in Phase 0: GitHub API (license, latest release, pushed_at, archived) on 2026-10-27, plus spec site search. Contributor counts, test coverage and doc quality were NOT measured systematically (see limitations).
